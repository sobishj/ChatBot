Demo business website

This page loads the chat widget exactly like a client website would. The ugly page styles are on purpose: the widget must look right anyway.

Open it with a client and API address in the URL:

http://localhost:5500/?client=CLIENT_ID&api=http://localhost:8000

Serve this folder on an allowed domain, e.g. python -m http.server 5500 inside demo/, and add localhost:5500 to the client's Allowed domains.
